  - Focuses on TensorFlow
  - Good introduction to concepts

## 📖 Books

### For Beginners

**General Introduction**
1. **"Artificial Intelligence: A Guide for Thinking Humans"** by Melanie Mitchell
   - Non-technical overview
   - Current AI landscape
   - Critical perspective

2. **"The Hundred-Page Machine Learning Book"** by Andriy Burkov
   - Concise introduction
   - Covers essential concepts
   - Good for quick overview

3. **"Make Your Own Neural Network"** by Tariq Rashid
   - Build from scratch
   - Understand fundamentals
   - Very accessible

**Python for ML**
1. **"Python Data Science Handbook"** by Jake VanderPlas
   - Free online
   - Comprehensive coverage
   - Good reference

2. **"Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow"** by Aurélien Géron
   - Practical approach
   - Code examples
   - Industry standard

### Intermediate to Advanced

**ML Theory**
1. **"Introduction to Statistical Learning"** by James, Witten, Hastie, Tibshirani
   - Free PDF available
   - R examples (but concepts apply broadly)
   - Excellent explanations

2. **"Pattern Recognition and Machine Learning"** by Christopher Bishop
   - Comprehensive
   - Mathematical depth
   - Reference book

**Explainable AI**
1. **"Interpretable Machine Learning"** by Christoph Molnar
   - **Free online book!**
   - Comprehensive guide to XAI
   - Must-read for XAI
   - Link: https://christophm.github.io/interpretable-ml-book/

2. **"Explainable AI: Interpreting, Explaining and Visualizing Deep Learning"** edited by Samek, Montavon, Vedaldi, Hansen, Müller
   - Advanced techniques
   - Research-oriented

## 📑 Research Papers

### Foundational Papers

**Machine Learning Classics**
- "A Few Useful Things to Know About Machine Learning" - Pedro Domingos (2012)
  - Practical wisdom
  - Avoid common pitfalls

**Explainable AI**
- "A Unified Approach to Interpreting Model Predictions" (SHAP) - Lundberg & Lee (2017)
  - SHAP framework
  - Influential paper

- "Why Should I Trust You? Explaining the Predictions of Any Classifier" (LIME) - Ribeiro et al. (2016)
  - LIME method
  - Local interpretability

- "Towards A Rigorous Science of Interpretable Machine Learning" - Doshi-Velez & Kim (2017)
  - Framework for interpretability
  - Evaluation methods

### Recent Surveys

- "Explainable Artificial Intelligence (XAI): Concepts, Taxonomies, Opportunities and Challenges" (2020)
  - Comprehensive overview
  - State of the art

- ✅ Up-to-date (ML field changes quickly)
