# Visuals Directory

This directory contains all visual content for the XAI_TR course, including diagrams, animations, and figures. Visual learning is a core principle of this course!

## 📁 Directory Structure

```
visuals/
├── diagrams/      # Flowcharts, concept diagrams, architecture diagrams
├── animations/    # GIFs and videos showing dynamic concepts
└── figures/       # Charts, graphs, and other static figures
```

## 🎨 Visual Content Guidelines

### Color Scheme

To maintain consistency and accessibility across all course materials, use this color palette:

#### Primary Colors
- **Blue (#2E86AB)**: Main concepts, primary elements
  - RGB: (46, 134, 171)
  - Use for: Key concepts, main flowchart elements

- **Purple (#A23B72)**: Advanced topics, secondary elements
  - RGB: (162, 59, 114)
  - Use for: Advanced concepts, optional content

- **Orange (#F18F01)**: Highlights, warnings, important notes
  - RGB: (241, 143, 1)
  - Use for: Attention items, highlights, warnings

- **Green (#06A77D)**: Success, positive outcomes, correct answers
  - RGB: (6, 167, 125)
  - Use for: Success indicators, correct examples

#### Supporting Colors
- **Light Gray (#F4F4F4)**: Backgrounds
- **Dark Gray (#333333)**: Text
- **White (#FFFFFF)**: Clean backgrounds, contrast

#### Accessibility
- All color combinations meet WCAG AA standards for contrast
- Use patterns or labels in addition to color
- Test with color-blindness simulators

### Design Principles

**Simplicity**
- Use clear, uncluttered layouts
- Focus on one concept per visual
- Remove unnecessary decoration

**Consistency**
- Use the same style across all visuals
- Maintain consistent spacing and alignment
- Use the standard color palette

**Clarity**
- Use readable fonts (minimum 12pt)
- Include legends where necessary
- Label all axes, elements clearly
- Add brief captions

**Beginner-Friendly**
- Avoid technical jargon in labels
- Use intuitive symbols and icons
- Include step numbers for processes
- Make relationships clear with arrows

## 📐 Diagram Standards

### Flowcharts
- **Shape conventions:**
  - Rectangle: Process or action
  - Diamond: Decision point
  - Rounded rectangle: Start/End
  - Parallelogram: Input/Output
  - Circle: Connector

- **Arrow styles:**
  - Solid line: Main flow
  - Dashed line: Optional or alternative path
  - Thick arrow: Emphasis or primary path

- **Spacing:**
  - Minimum 20px between elements
  - Align elements on grid

### Concept Diagrams
- Use visual metaphors when possible
- Show relationships with connecting lines
- Group related concepts visually
- Use size to indicate importance

### Architecture Diagrams
- Show data flow with arrows
- Use layers for hierarchy
- Label all components
- Indicate data types/formats

## 🎬 Animation Specifications

### Format
- **Preferred:** MP4 (for compatibility) or GIF (for simple animations)
- **Resolution:** 1920x1080 or 1280x720
- **Frame rate:** 30 fps
- **Duration:** 10-30 seconds (keep it short!)

### Style
- Use smooth transitions
- Highlight changes with color
- Add text annotations
- Include pause points for complex concepts

### File Size
- GIF: Maximum 5MB
- MP4: Maximum 20MB
- Compress without losing clarity

### Accessibility
- Include text alternatives
- Add captions or descriptions
- Don't rely solely on color changes
- Ensure key frames are clear when paused

## 📊 Figure Standards

### Charts and Graphs
- Clear axis labels with units
- Readable legends
- Data source citation
- Consistent color scheme
- Grid lines for readability (subtle)

### Screenshots
- High resolution (at least 1280px wide)
- Crop to relevant content
- Add annotations with arrows/boxes
- Use red circles/arrows for highlighting

### Photos
- High quality (at least 1920px wide)
- Good lighting and focus
- Relevant to content
- Properly attributed

## 📝 File Naming Conventions

Use descriptive, consistent names:

```
{module-number}-{topic}-{type}-{number}.{extension}

Examples:
- 01-ai-overview-diagram-01.svg
- 05-model-training-animation-01.gif
- 06-shap-explanation-figure-01.png
```

**Guidelines:**
- Use lowercase
- Separate words with hyphens
- Include module number if module-specific
- Number sequentially
- Use appropriate file extension

## 📦 File Formats

### Vector Graphics (Preferred for Diagrams)
- **SVG**: Scalable, best for web

### Raster Graphics
- **PNG**: For diagrams, screenshots (lossless)
- **JPEG**: For photos (lossy, smaller size)
- **GIF**: For simple animations

### Videos
- **MP4**: Best compatibility
- **WebM**: Good for web, smaller size

## 🎯 Creating Effective Educational Visuals

### Before Creating
1. **Define the goal**: What should students learn?
2. **Identify the audience**: Complete beginners or some experience?
3. **Choose the format**: Diagram, animation, chart?
4. **Sketch first**: Plan layout on paper

### During Creation
1. **Stay focused**: One concept per visual
2. **Use the style guide**: Colors, fonts, spacing
3. **Add context**: Labels, captions, legends
4. **Test readability**: Can you understand it without explanation?

### After Creation
1. **Get feedback**: Ask someone to review
2. **Test accessibility**: Color-blind simulation, contrast checker
3. **Optimize file size**: Compress without quality loss
4. **Document**: Add README or caption

## 🔍 Accessibility Tips

**For All Visuals:**
- Provide text alternatives (alt text, captions)
- Don't rely solely on color
- Ensure sufficient contrast (4.5:1 minimum)
- Use patterns in addition to colors

**For Diagrams:**
- Include text descriptions in documentation
- Use labels, not just colors
- Make text large enough to read

**For Animations:**
- Provide static alternatives
- Include captions or transcripts
- Allow pausing
- Don't flash rapidly (seizure risk)
